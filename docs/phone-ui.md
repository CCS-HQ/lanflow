# 手机界面（iOS / Android）

`view.Options.Phone` 为真时（`main_phone.go`），澜流画手机界面；为假时桌面布局完全不变。
外壳在 `internal/view/shell_phone.go`，页面通过 `env.Env.Phone` 得知自己在手机上，共用的手机部件在 `internal/view/env/phone.go`。

目标是像手机 App，而不是桌面窗口缩窄：一个主操作（连接）、大标题、无边框的卡片和分组列表、顶部栏图标按钮，没有桌面风格的描边小按钮。

## 外壳

```
┌──────────────────────────┐  ← 安全区（状态栏、刘海）由窗口根节点让出
│ 〈设置    常规      ⚡ ⋯  │  ← 顶部栏：返回 / 标题 / 页面的图标按钮（env.PhoneBar）
│ 代理                     │  ← iOS 大标题（页面滚动内容的第一行；滚走后顶部栏显示小标题）
│                          │
│     页面内容（单列）       │
│                          │
├──────────────────────────┤
│ 首页 代理 订阅 活动 设置   │  ← 底部栏 mobile.BottomBar
└──────────────────────────┘
```

- **底部 5 个标签**：首页、代理、订阅、活动、设置。活动标签显示活动连接数角标，抓包解密中时设置有圆点角标。
- **活动**：和其他标签一样有大标题（iOS），其下一个全宽分段控件「连接 / 地图 / 日志」，只有这一层分段。各分段的操作在顶部栏：连接为筛选（活动 / 已关闭）、暂停、⋯（全部断开，二次确认）；日志为暂停、⋯（级别、复制、导出诊断、清空）；地图为刷新（实测出口）。离开再回到活动时停在上次的分段。
- **设置**：分组列表（iOS inset grouped，Material 平铺列表），彩色图标方块：
  - 常规、代理、DNS、嗅探、覆写、内核、高级（TUN 和 Agent 不列：手机的 VPN 就是 TUN，手机上没有本机接口）；
  - 工具：规则、网络、统计、检测、抓包（设置里打开后才出现）、聚合订阅。
  - 点一行推入该页，顶部栏有返回按钮（iOS「〈 设置」，Material 只有箭头），标题为分栏或页面名。设置页在手机上不显示分栏标签。
- **顶部栏**：自绘（`phoneTopBar`）。iOS 高 44、标题居中；Material 高 56、标题左对齐、字号 22。页面实现 `env.PhoneBar` 时，外壳在右侧画它的图标按钮（`env.IconButton`，44×44 无边框）。
- **大标题**：iOS 上首页、代理、订阅、设置列表以大标题开头（`env.LargeTitle`），页面主滚动容器跟踪 `Env.PhoneScroll`，滚过 44pt 后顶部栏显示小标题；活动的大标题固定在分段控件上方（各分段的列表各自滚动）；Material 不显示大标题。
- **页面内推入**：页面可实现 `env.PhoneStack`（`PhoneSub`、`PhonePop`），在自己内部推入一页（连接详情、设置的编辑页与选择页），外壳显示它的标题和返回按钮（iOS 写上一页名，如「〈 连接」「〈 代理」），返回与 Android 返回键先关闭它。
- **导航模型**：沿用 `Shell.navigate(page, arg)`，外壳多三个状态：`phoneHub`（显示设置列表）、`actSeg`（活动的分段）、`scrolls`（各页滚动位置）。页面之间的跳转照常工作：跳到连接或日志时切到活动的对应分段，跳到工具页时底部选中设置。
- **返回**：页面内推入的页 → 推入页 → 设置列表 → 首页；Android 返回键（`ui.KeyBack`）同样逐级返回，在首页上不拦截，交给系统（退出 App）。页面自己的返回（连接详情 → 连接列表）先处理；对话框打开时由对话框处理。
- **不显示**：侧栏、全局搜索、快捷键、拖放导入、托盘提示、系统代理恢复提示。对话框、确认框与桌面共用；提示条级别与桌面相同，位置按平台：iPhone 在状态栏下方、上滑收起，Android 是标签栏上方的 Snackbar、侧滑收起（[notifications.md](notifications.md)）。

## 各页

- **首页**（`overview/phone.go`）：
  - 中间直径 124pt 的圆形连接按钮：未连接灰、连接中强调色并有呼吸光环、已连接绿色、出错或缺内核红色；按下略缩小。
  - 下方大字状态（已连接 / 未连接 / 正在连接… / 连接出错），已连接时下一行只写时长（「已运行 2 小时 13 分」），再下一行 ↑↓ 实时速度；出错时显示错误文字和「查看日志」。
  - 全宽模式分段（规则 / 全局 / 直连）。
  - 当前节点卡片：主代理组经子组追到的节点、经过的组、协议、延迟；点击打开代理页并选中主代理组。
  - 当前订阅卡片：名称、已用 / 总量、到期、用量条；点击打开订阅页。
  - 出口地图不在首页（在活动 › 地图）。
- **代理**（`proxies/phone.go`）：
  - 顶部可横向滚动的代理组胶囊，选中为实心强调色；胶囊里的图标是配置里该组的 `icon`，没有就不显示（测试数据给「节点选择」配了一个蓝色圆形加号图标，快照里看到的就是它）；下面一行「当前 X · N 个节点」。
  - 页尾「代理集合」与节点卡片同样是无边框表面色，更新和健康检查是无边框图标按钮。
  - 节点为双列卡片网格（名称、协议、延迟按颜色），整张卡片可点选，选中卡片强调色底和边框；整页是一个按行渲染的虚拟列表，几百个节点也只建可见的行。
  - 顶部栏：闪电「测速当前组」；⋯ 菜单：搜索节点、排序、定位当前节点、设为主代理组、添加节点、链式代理。卡片长按：测速、编辑 / 删除手动节点、链式代理。
- **订阅**（`subs/phone.go`）：
  - 大标题，顶部栏「＋」导入菜单（从链接导入、从文件导入、新建聚合订阅）。
  - 无边框卡片：名称、当前订阅的对勾、「更新于 … · 到期 …」（更新失败、临近到期用警告色，已过期用危险色）、用量条与百分比。
  - 点卡片切换为当前；左滑出现编辑、删除（`mobile.SwipeRow`，当前订阅只有编辑）；长按菜单放其余操作（更新、查看配置等）；下拉刷新为全部更新（`PullToRefresh`）。
  - 聚合订阅（设置 › 工具）：无边框卡片，整卡点开编辑器，长按菜单为使用 / 更新 / 删除，顶部栏「＋」新建。
- **活动 › 连接**：无边框的系统样式搜索栏，其下连接数（或「已关闭」）；列表行（主机 / 进程 · 规则 · 链路 · 速度，行高 56）；点一行推入详情（顶部栏「〈 连接」返回），详情的操作是分组里的文字行（此域名始终走…、此程序始终走…、红色的断开此连接）；没有拓扑视图。
- **活动 › 地图**：出口地球占满屏宽（没有卡片和「出口地图」小标题），手指拖动旋转、双指缩放、双击复位，没有 ＋ − 和定位按钮；其下「当前出口」「其他路由」两组分组列表行（颜色、节点、组 · 城市 · 实测 · 速度 · 连接数、延迟），点一行打开代理页的该组。
- **活动 › 日志**：全宽「内核 / 澜流」分段；无边框搜索栏；每条两行（时间与级别 / 可换行的内容）。
- **设置各分栏**：手机原生的分组列表行，没有描边输入框、按钮和下拉框（`settings/phone.go`、`phone_forms.go`、`phone_general.go`）：
  - 左边标题，说明在行内第二行（小一号）或分组脚注；右边当前值和 ›（`env.NavRow`）。
  - 点值行推入**编辑页**（全宽输入框、说明、完成；数字用数字键盘；返回即保存，校验失败时留在页内显示错误）或**选择页**（带对勾的列表，选中即返回）；开关行保留开关。
  - 操作是整行可点的**动作行**（`env.ActionRow`，强调色，危险操作红色），如导出设置、导入设置、清理缓存、立即备份、重启内核、更新地理数据库。
  - 列表类设置每项一行、末尾一行「添加…」：按 Wi-Fi 切换订阅（Wi-Fi → 订阅）、按域名指定服务器（域名 / → 服务器）、覆写列表；点一项推入它的编辑页，删除是编辑页里的红色动作行。
  - 原来的设置对话框（导出、同步口令、WebDAV、上报令牌、服务器上的备份、hosts）改为推入页；覆写的 YAML 编辑器与运行时配置仍是对话框。
  - DNS、嗅探、高级的「应用 / 放弃」在底部，是动作行。
  - 只对桌面成立的说明（托盘、菜单栏、访达、凭据管理器、网卡举例）在手机上换成不提它们的说法。
- **规则、网络、统计、检测**：两行列表、单列。

通用：内容左右边距 16（`env.PhoneGap`），圆角 12（`env.PhoneRadius`），卡片用表面色叠在背景上、不加边框（`env.PhoneCard`），分段控件全宽等分（`env.Segmented`，iOS 选中段浮起，Material 选中段着色），可点区域 ≥ 44pt（`env.TouchSize`）。外观由 `mobile.Current()` 决定：iOS 为 Cupertino，Android 为 Material。

## 开关：只有一个 VPN

手机上内核只在系统 VPN 里运行（`internal/platform/tunnel`、`internal/app/deps_phone.go`；隧道的 Runner 总把 TUN 指向 VPN 的 fd），所以 VPN 就是内核，设置里的 TUN 字段在手机上没有意义：

- 连接：`StartCore()`；首次开启时系统弹出的 VPN 授权由隧道实现处理，启动失败时错误文字以提示条显示，并留在按钮下方；
- 断开：`StopCore()`；
- 状态取自 `Status().Core` 与 `CoreError`。

只用服务层已有的动作，没有新增接口。

手机上隐藏的项：

| 位置 | 隐藏 |
|---|---|
| 首页 | 内核开关、系统代理开关及首次提示、TUN 开关、终端代理命令、出口地图（移到活动） |
| 设置 › 常规 | 开机时启动、管理员启动、启动后自动开启系统代理、启动时不显示窗口、关闭窗口时、全局快捷键、菜单栏显示、配置文件夹、应用更新 |
| 设置 › 代理 | 允许局域网连接（及无认证警告）、不走代理的地址 |
| 设置 › 内核 | 内核版本管理、内核更新、内核文件（改为只读的「内核版本」一行） |
| 设置 › 高级 | 允许 / 禁止的局域网地址、系统代理（PAC）、TUN 参数 |
| 设置 › TUN、Agent | 整个分栏不列出 |
| 启动时 | 系统代理恢复提示（手机上没有系统代理可恢复） |

## 性能与电量

出口地球在手机上不播放闲置动画（摇摆、「你」的脉冲），请求流动画限 30 fps，只在活动 › 地图显示时绘制；页面离开或 App 进入后台时照常释放绘制缓存（`Hidden`）。连接按钮的呼吸光环只在连接中时动。代理页的节点网格是虚拟列表。

## 没做的

- 规则、网络、统计、检测、抓包页（设置 › 工具）的工具栏和其中的对话框（添加规则、添加网站等）仍是窄屏版的桌面控件，没有改成列表行。
- 设置里的推入页只有一层（`Page.sub`）：推入页里不能再推一层，所以覆写的改名放在它的页面里直接编辑。
- 同步口令、合并选择、服务器上的备份、WebDAV 密码、上报令牌几个推入页只编译和走过部分测试，没有快照。
- iOS 从左边缘滑动返回、点状态栏回到顶部：外壳没有用 `ui.Router`，要等改用 `Router`（`SystemStack`）后才有。
- 代理页选中的组只在内存里，重启后回到主代理组（持久化要在 `model.UIState` 加字段）。
- 规则、统计列表在手机上不能按列排序；对话框里的按钮仍是默认高度。
- 下拉刷新、左滑、长按菜单和文件导入导出的手感未在真机验证（MyGo 在桌面上关掉了回弹，测试里拉不动，只覆盖了刷新状态的逻辑）；整个界面只有无窗口测试和快照，没有在模拟器或真机上运行过。
- 抓包页没有做窄屏适配；抓包在手机上需要用户手动信任根证书，界面未做引导。
