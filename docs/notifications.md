# 通知与提示

桌面和手机用同一套通知规则：按「需要用户做什么」分级，级别决定形式和停留时间，位置按各平台的习惯摆放。代码入口是 `env.Env.Notify`（`internal/view/env/notify.go`），外壳在 `internal/view/shell_toast.go` 里按平台绘制。

## 级别

| 级别 | 用途 | 形式 | 停留 |
|---|---|---|---|
| ① 操作反馈 `env.Done` | 用户刚做的事有了结果，而界面上看不出来：「已复制」「规则已保存」「已切换到 东京 03」 | 提示条，绿色对勾 | 2 秒 |
| ② 消息 `env.News` | 服务主动告诉用户的事：自动更新成功、新版本、为用户调整了设置 | 提示条，蓝色信息图标 | 4 秒 |
| ③ 需要注意 `env.Attention` | 失败，或用户必须知道的结果：订阅更新失败、内核意外退出 | 提示条，红色警告图标，带下一步操作（查看详情、查看日志、前往设置） | 6 秒 |
| ④ 持续状态 | 只要状态在就一直成立：内核未运行、订阅即将到期、DNS 跟随订阅不可改、配置无效 | 页面横幅（`Kit.Banner`），在页面标题下方 | 状态消失才消失 |
| ⑤ 需要决定 | 退出确认、恢复系统代理、无效配置 | 桌面对话框；手机底部弹出层 | 用户选择后关闭 |
| ⑥ 后台事件 | 窗口隐藏或 App 在后台时：内核崩溃、订阅自动更新失败 | 系统通知（`Notice.System`，§9） | 由系统管理 |

规则：

- 界面本身已经能看出结果的（开关已经翻转、列表已经刷新），不再弹操作反馈。
- 失败一定要说接下来怎么办：「仍在使用上次的配置」「检查网络后重试」，并尽量给出操作按钮。错误提示的「查看详情」打开全文，可复制。
- 持续状态不用提示条：提示条几秒就消失，状态却还在。
- 鼠标停在提示条上、或键盘焦点在其中时暂停计时；任何时候都可以手动关闭。

## 合并与堆叠

- 同时最多显示 3 条（MyGo 的 `toastLimit`），超出时最早的先收起。
- 同一条消息（同一级别、同一文字，或相同的 `Note.Key`）正在显示时再次出现，不新增一条，而是替换原来那条、重新计时，并在末尾显示次数：「已复制 ×2」。提示条收起后计数归零。

## 位置

| 平台 | 位置 | 出现方式 | 收起 |
|---|---|---|---|
| 桌面 | 页面区域左下角 | 从下方淡入 | 右侧「关闭」，或 Esc |
| iPhone / iPad（Cupertino） | 状态栏下方，左右各留 12pt，铺满宽度 | 从上方滑入，盖在大标题上 | 向上滑动超过 40pt |
| Android（Material） | 底部标签栏上方的 Snackbar；键盘弹出时在键盘上方 | 从下方滑入 | 左右滑动超过 40pt |

桌面为什么是左下角：页面顶部是标题行（标题、代理页的「搜索节点」、工具按钮），紧接着是提示最常回应的控件（概览的内核、系统代理、TUN 开关）；底部居中有地图的缩放和定位按钮、日志页的「回到底部」；右下角有终端代理的「复制」和表格的末列。左下角是各页刻意留空的位置。这次统一时实际试过顶部居中、标题行下方、底部居中三种位置，分别挡住了代理页的搜索框、概览的开关、地图的缩放按钮，所以桌面保留左下角，只统一级别、时长和合并规则。

手机上没有指针可以瞄准，所以提示条不画关闭按钮，用滑动收起；操作按钮高度不小于 44pt。Android 的 Snackbar 用反色（浅色外观下是深色条），没有图标，只有失败时带一个警告图标。

## 用法

```go
e.Toast(i18n.T("已复制"), false)                      // 操作反馈（Done）
e.Toast(err.Error(), true)                             // 需要注意，带「查看详情」
e.Note(env.Note{Level: env.News, Title: i18n.T("…")}) // 其他级别、操作按钮、合并键
e.Run(job, i18n.T("订阅已更新"))                       // 成功时操作反馈，失败时需要注意
```

`Env.Note` 在没有外壳的页面测试里退回到 `Toast`。服务层的 `app.Notice` 由外壳转换：`core-crash` 为需要注意并带「查看日志」，`error` 为需要注意，其他为消息；`invalid-config`、`recovery`、`crash-report` 是对话框。

## 测试

`internal/view/notify_test.go`：级别时长与合并键、重复消息合并为「×2」、桌面位置（代理页显示提示时仍能点到搜索框）、手机两种外观的位置（不超出屏幕、iPhone 不压状态栏、Android 不压标签栏）和滑动收起。手机快照 `TestPhoneSnapshots` 含 `toast-done`、`toast-error`、`toast-merged`、`toast-core-crash`。
